# Lanyard Assets

This directory contains the required assets for the Lanyard component:

## Required Files:
1. **card.glb** - 3D model file for the ID card
2. **lanyard.png** - Texture image for the lanyard band

## Instructions:
1. Download the `card.glb` and `lanyard.png` files from the original repository
2. Place them in this directory (`src/assets/lanyard/`)
3. You can edit the card.glb file using: https://modelviewer.dev/editor/
4. You can edit the lanyard.png texture in any image editor

## File Locations:
- `src/assets/lanyard/card.glb`
- `src/assets/lanyard/lanyard.png`
